# Replica Evidence Workspace

Task-specific evidence and progress artifacts for Restaurant POS OS. Not production code or a second source of architectural truth.

Expected artifacts: recon.md, features.csv, test-plan.md, parity.md, build-log.md, risks.md.

Evidence rules:
- Cite repository paths/line ranges, PRs, commits, CI runs, supplied PDFs, or screenshots.
- Separate observed facts, assumptions, and proposed behavior.
- Status values: not-started, partial, verified, blocked.
- Every verified row needs reproducible test or direct evidence.
- Never invent screenshots, metrics, tests, reviews, or completion percentages.
- Do not copy proprietary assets, source, or copy from reference products.
- Keep customer, employee, and payment-sensitive data out.
- Do not generate speculative full-system inventory before reading actual UI/source and the supplied UI Directions PDF.
